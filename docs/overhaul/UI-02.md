# UI-02 — correlated numeric completion

`Entry_Transaction.lua` owns one bounded mailbox per GUIDANCE, ALT, NAV and STORES
lane. `F22_ENTRY_<lane>_REQUEST/ACTIVE/COMMAND/VALUE` precedes device command
11800 carrying the request token. The owner publishes `ACK_VALUE/RESULT`, then
`ACK_REQUEST` last (RESULT 1 accepted, 2 rejected). Tokens are exact integers
1–16777215; exhaustion rejects further requests until the mission partition is
reset. Legacy direct owner commands remain supported.

Cancellation/timeout withdraws ACTIVE. Owners reject delayed, duplicate, stale
or cancelled tokens before application. A new equal value still requires its own
completion. Native guidance acknowledges the actual target commit, in existing
units; heading publication/readback is degrees. Magnetic entry converts once at
the boundary. NAV additionally acknowledges id, decimal-degree coordinates and
MSL elevation feet; selected waypoint ID cannot acknowledge a same-ID edit.
Stores retains ENTRY_FIELD-zero and achieved-value checks in addition to the
weapons owner's commit token. ALT completion refers to accepted local settings;
actual pressure-altimeter measurement validity remains separate.

The deliberate same-option submit, CLR-all and one-digit UNDO policy is retained.
ED Hornet guide (24 March 2024), p47 establishes explicit valid/error feedback,
not this exact F-22 key sequence. The actual UFC/NAV/local owner regression covers
0/1/90/123/359, magnetic north crossing, same-ID, drop, delay, reorder, cancel and
power loss; the built DLL test independently covers native accepted/rejected,
zero, duplicate and cancelled requests. Flight tracking is not claimed.

WARN is a device-scoped11800 lane owned by PILOT_WARNING_SYSTEM. Its11035 disable-current-low command accepts only a fresh active event and acknowledges the actual event ticket. ALT11036 changes manual recovery intent; entering it never commands an automatic mode.
