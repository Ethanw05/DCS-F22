# Trim correction — 2026-10-27

Implemented and installed after the recorded 02:22 local flight. Existing hat
assignments to the inherited repeated trim commands remain unchanged.

## Research and boundary

Eagle Dynamics' [Viper manual, manual trim panel, page 72](https://www.digitalcombatsimulator.com/upload/iblock/3dc/5p9ejw7gi488n9zd15csrxxs8os2dflk/DCS_F-16C_Early_Access_Guide_EN.pdf)
documents pitch/roll trim through the flight-control system, with normal and
trim/autopilot-disconnect control paths. This supports keeping trim within the
flight-control command processing rather than assigning a fixed surface increment
to every input callback. It does not disclose this mod's appropriate gains or an
F-22 trim law.

NASA's [2023 reversionary control study](https://ntrs.nasa.gov/api/citations/20230009398/downloads/TM-20230009398%2007.17.23.pdf)
describes preserving control-state continuity across mode transfers. Applied here
as a limited engineering principle: retain the existing equilibrium correction
while manual trim moves, rather than moving/erasing that correction on first press.
This is not an implementation of that paper's complete controller.

## Changes

- Trim callbacks now select a direction; simulation time advances trim. Callback
  repetition alone causes no change. Pitch rate is 0.04 normalized command/s;
  roll and yaw are 0.02/s. Pitch manual authority is limited to +/-0.25; lateral
  authority retains +/-0.2. These are mod tuning values, not real F-22 data.
- Native trim-stop command 215 releases all trim directions. The two legacy
  nose-up/down aliases now send trim-stop on release as the inherited hat already
  did. Only these two corrections were patched into installed input files.
- Pitch trim temporarily freezes the automatic correction while held, then for
  0.25 seconds after release. It no longer moves auto trim into manual trim or
  permanently latches automatic stabilization off. Existing automatic correction
  resumes its bounded adjustment after the handoff.
- The existing automatic controller seeks zero pitch rate when the stick is
  neutral; this fix retains that behavior. It arrests continued rotation after a
  trim adjustment and does not implement F-16 normal-acceleration command laws,
  altitude hold, or a documented production F-22 FLCS.
- Trim still disconnects engaged flight autopilot. Reset clears manual offsets,
  directions and the temporary handoff; existing automatic correction is retained.
- Electrical availability gates trim motion. Flight-model reset clears held trim.
  Diagnostic fields remain enabled. `MANUAL` and inhibit bit 8 now mean temporary
  manual activity/handoff, replacing the previous permanent latch semantics.

automatic correction, bounded resumption, actual autopilot engagement followed

history. Timestamp sampling limits how precisely short presses can be recreated.
